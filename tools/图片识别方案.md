# 图片识别双层策略（OCR 优先 + 视觉模型兜底）

背景：当前默认模型（DeepSeek 文本模型）没有视觉能力，聊天框也无法直接传图分析。
按「本地 OCR 优先、视觉模型兜底」两层设计：

## 第一层：本地 OCR（免费、离线）

1. 安装 Tesseract：
   winget install UB-Mannheim.TesseractOCR
   （安装向导勾选 Chinese Simplified 语言包）
2. 使用本目录脚本：
   .\tools\ocr-image.ps1 -ImagePath C:\path\to\image.png
3. 特点：纯文字图片约 2-3 秒、完全免费；表格/手写/复杂排版效果一般。
4. 把 OCR 输出的文字直接粘贴给 AI 即可（绕开聊天框传图限制）。

## 第二层：视觉模型（需要 API key，识别复杂图片/理解画面）

生态里已有现成插件，任选其一：

| 插件 | 仓库 | 说明 |
|---|---|---|
| dsh-img | github.com/gmleong/dsh-img | 给纯文本模型装眼睛：analyze_image 工具，支持 GLM-4V-Flash（有免费额度）/Qwen-VL/任意 OpenAI 兼容端点 |
| dsh-plugin-deepeye | github.com/Favio8/dsh-plugin-deepeye | DeepEye：图片描述、OCR、VQA、UI 布局、剪贴板分析 |
| dsh-ocr-plugin | github.com/CraZY222123/dsh-ocr-plugin | 专用 OCR |

安装方式（示例）：
  dsh plugin --profile web add github:gmleong/dsh-img

然后在插件配置里填入视觉模型的 API key（如智谱 GLM-4V-Flash 的免费 key），
之后会话里就能让 AI 用 analyze_image 工具看图了。

注意：视觉模型生成的内容由对应厂商提供；上传图片请自行注意隐私。
